# Mapas de exemplo

Os dois pacotes **TesteProdutivo** foram criados do zero com as ferramentas
do Dungeon Keeper Studio. Nao sao copias editadas de fases da campanha.
Sao arquivos de nivel, nao uma distribuicao dos recursos comerciais do jogo.
Exigem uma instalacao legal de Dungeon Keeper e, no perfil correspondente,
uma instalacao completa do KeeperFX.

- `TesteProdutivo-Gold\map00300.*`: formato classico, mapa 300.
- `TesteProdutivo-KeeperFX\map05000.*`: formato estendido, mapa 5000.

Vermelho humano contra Azul com IA. Cada base possui coracao, imps, portal,
salas iniciais e ouro. O objetivo e destruir o coracao do adversario.

## Instalacao pelo editor

1. Configure os executaveis do jogo no Studio.
2. Abra o arquivo `.slb` do pacote desejado.
3. Use **Exportar ao jogo** e confirme um numero livre.
4. Use **Testar** para abrir a missao exportada.

Nao copie arquivos por cima de um mapa existente. O numero usado na
exportacao pode ser diferente do exemplo se o destino ja estiver ocupado.
Mapas de campanha importados, suas edicoes e backups locais nao devem
ser adicionados a este repositorio sem verificar os direitos aplicaveis.
